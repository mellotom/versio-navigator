# versio-navigator

travelers guide for traversing the versio starsystem: a one-page reference for the noise engineering versio platform. every noise engineering firmware and the community firmwares (acidclank, audiority, onoma2, s3g, blue nautilus and more) with what each claims to do, its price and where to get it. every control is named by its number on the numbered versio panel.

live page: https://mellotom.github.io/versio-navigator/
part of the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

compiled from noise engineering's manuals and accessibility documentation, each firmware developer's own pages, and the community firmware index (github.com/Maxhodges/noise-engineering-firmware-index). not affiliated with noise engineering or any firmware developer.
